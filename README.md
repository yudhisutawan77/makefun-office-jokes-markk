## The joke

> I asked to be removed from a reply-all thread, so 400 colleagues replied-all to say they want out too.

One line about office life, 102 characters — inside the 1–199 gate. It turns
on the most recognizable office detail there is, the reply-all storm, and
the laugh lands on the final beat: the very people trying to escape the
thread become the thread.

## How it works

`main.py` writes the joke to `/output/entry.txt` (or `$ENTRY_OUT/entry.txt`
when that variable is set) and prints it exactly once to stdout. It
validates the gate itself before writing: UTF-8 text, 1 to 199 characters,
a single line, not only whitespace.

```sh
python3 main.py
```
